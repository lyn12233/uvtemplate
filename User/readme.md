## description on `User/`

main dir for user codes

- `crypto/`: cryptography functions for ssh
- `esp/`: esp8266's uart manager and socket api provider
- `ssh/`: ssh and sftp protocol implementation (**singleton**)
- `types/`: vstr_t(variable length string/buffer), vo_t(variant object), vo_type_t, vlist_t
- `wiz/`: W5500 module's manager
